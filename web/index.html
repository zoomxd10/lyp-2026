Cómo hacer una buena foto
  • Las cartas se leen como un libro: filas de arriba abajo, cada fila de izquierda a derecha.
  • Sepáralas un poco para que no se tapen entre sí.
  • Vale una mesa blanca o cualquier fondo liso, con buena luz, sin reflejos y sin otros objetos.
  • Haz la foto desde arriba, con todas las esquinas visibles.

La página compara cada carta con fotos de referencia de vuestra baraja, en tu propio dispositivo. Toca cualquier carta detectada para corregirla antes de ponerla en la mesa.

El mazo

Una sola baraja: cada carta solo se puede poner una vez. Si hay una carta seleccionada en la mesa, la nueva se coloca justo detrás.
